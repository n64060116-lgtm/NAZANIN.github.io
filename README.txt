RUN THE WEBSITE
1. Extract this ZIP completely; do not open the HTML files while they are still inside the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Choose Persian or English in the language switcher. The site changes direction from RTL to LTR as well as changing the text.
4. Use the Certificates link to view the certificate and each project card to open its own detail page.
